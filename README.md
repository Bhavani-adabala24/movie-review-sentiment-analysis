# movie-review-sentiment-analysis
Built a Sentiment Analysis project using Python, NLP, and Machine Learning to classify IMDb movie reviews as Positive or Negative. Implemented text preprocessing, stemming, stopword removal, CountVectorizer, and Multinomial Naive Bayes with the IMDb dataset. Achieved sentiment prediction with real-time user input support.

Python
NLTK
Scikit-learn
Pandas
NumPy
Hugging Face Datasets
